# NiangAtelier Homepage Implementation Plan

**Goal:** Build only the approved quiet gallery homepage, with no generated or external imagery.

**Architecture:** App Router server components compose the five requested sections. A typed static content file supplies optional local image sources. Native CSS provides shared tokens, responsive layouts and reduced-motion support. No database or client-side application state.

**Tech Stack:** Next.js 15, React 19, TypeScript, native CSS; system fonts.

1. Initialize package/config files with only framework and TypeScript dependencies.
2. Define content in `src/data/home.ts` and a reusable `ArtworkImage` with an empty, accessible warm-white state and optional Next Image rendering.
3. Compose Header, Hero, Featured Works, About teaser and Footer in that exact order. Internal navigation targets existing home sections. Unavailable studio/social destinations remain explicitly disabled until supplied.
4. Style desktop with 64–96px margins, a split hero, staggered two-column works, and 120–180px section spacing. Mobile uses 20–24px margins, 40–56px title and single-column images.
5. Run `npm run build` and `npm run typecheck`. Inspect desktop/mobile browser rendering, document overflow, anchors, section structure, palette, motion preferences and runtime errors. Document outcomes in README.

No additional routes, imagery, UI libraries, animation libraries, commerce, backend, Git push or deployment.
